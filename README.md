# sarajkrishnasingh.github.io

Personal website and résumé for **Saraj Krishna Singh**, served at [https://sarajkrishnasingh.github.io](https://sarajkrishnasingh.github.io).

## What’s in this repo

- `index.html` — home page (about, experience, skills, projects, socials)
- `resume.html` — typographic résumé, with a print stylesheet
- `resume.md` — the same résumé in Markdown
- `styles.css` — site styles
- `assets/` — favicon and icons
- `.nojekyll` — serve the site as plain static files on GitHub Pages

The site is static HTML and CSS. GitHub Pages is configured to publish from the `main` branch root.

## Local preview

```bash
python3 -m http.server 8080
```

Then open [http://localhost:8080](http://localhost:8080).
